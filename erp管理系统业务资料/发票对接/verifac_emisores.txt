CONSULTA DE EMISORES:

Caso de consulta de todos los emisores del cliente:
{
	"cliente": {
		"nif": "XXXXXXXXX",
		"codigo": "XXXXXXXXXXXX"
	},
	"operacion": "consulta_emisor"
}


Caso de consulta de todos los emisores con un NIF:
{
	"cliente": {
		"nif": "XXXXXXXXX",
		"codigo": "XXXXXXXXXXXX"
	},
	"operacion": "consulta_emisor",
	"emisor": {
		"nif": "XXXXXXX"
	}
}

{

	},
