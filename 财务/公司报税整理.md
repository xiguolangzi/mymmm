# 公司报税整理

## 1工资

### 	1.1 个人交税

```java
// 1 BBC/C	基础社保
	1322.88
    
// 2 S.S. TRABA	个人社会保险(公司部分)
    -- COTIZACION CONT.COMU	社会保险	4.8%
    -- COTIZACION FORMACION	职业培训费	0.1%
    -- COTIZACION DESEMPLEO	失业保险	1.6%
    = 4.8% + 0.1% + 1.6% = 6.5%
    = 基础社保 * 6.5%
    = 1322.88 * 6.5% = 85.99

// 3 I.R.P.F 个人所得税(个人部分)
    -- TRIBUTACION I.R.P.F. 个人所得税	2%
    = 基础社保 * 2%
    = 1322.88 * 2% = 26.46
```

### 	1.2 个人银行实发工资

```java
// 1 BRUTO 基本工资
	-- Salario Base 基础工资			998.49 = 30 * 33.283
	-- P.P. Paga extra 额外支付 	249.6
	-- Plus Transporte 交通补助 	74.79
  = 基础工资 + 额外支付 + 交通补助
	= 998.49 + 249.6 + 74.79 = 1322.88
  
// 2 BASE IRPF 所得税基数
  = 基本工资
  = 1322.88
    
// 3 LIQUIDO 银行实发工资
    = 基本工资 - 个人社会保险 - 个人所得税
    = 1322.88 - 85.99 - 26.46 = 1210.43
```

### 	1.3 公司总支出

```java
// 1 S.S EMPRE	公司额外交税
	-- COTIZACION CONT.COMU 社会保险	24.1%
  -- COTIZACION FORMACION	职业培训费	0.6%
  -- COTIZACION DESEMPLEO	失业保险 6.7%
  -- AT y EP 工伤和职业病保险	2.6%
  -- Fondo Garantía Salarial	工资保障基金	0.2%
  = 24.1% + 0.6% + 6.7% + 2.6% + 0.2% = 34.2%
	= 员工基础社保 * 34.2%
  = 1322.88 * 34.2% = 452.43
    
// 2 TOTAL TC1	公司总交税
    = 员工个人社会保险 + 公司额外交税
    = 85.99 + 452.43 = 538.42

// 3 CTE EMPRES 公司总支出
    = 银行实发工资 + 公司总交税 + 员工个人所得税
    = 1210.43 + 538.42 + 26.46 = 1775.31
```

### 	1.4 员工工资总结

```java
// 1 基础工资
	= 基础社保
	= 1322.88
// 2 公司需要缴纳总税率
  -- COTIZACION CONT.COMU 社会保险	24.1%
  -- COTIZACION FORMACION	职业培训费	0.6%
  -- COTIZACION DESEMPLEO	失业保险 6.7%
  -- AT y EP 工伤和职业病保险	2.6%
  -- Fondo Garantía Salarial	工资保障基金	0.2%
  = 24.1% + 0.6% + 6.7% + 2.6% + 0.2% = 34.2%

// 3 公司为个人缴纳中税率
    -- COTIZACION CONT.COMU	社会保险	4.8%
    -- COTIZACION FORMACION	职业培训费	0.1%
    -- COTIZACION DESEMPLEO	失业保险	1.6%
    = 4.8% + 0.1% + 1.6% = 6.5%
    
    -- TRIBUTACION I.R.P.F. 个人所得税	2%
// 4 公司实际缴纳的总税率
    = 公司需要缴纳总税率 + 公司为个人缴纳中税率
    = 34.2% + 6.5% + 2%
    = 42.7%
    
// 5 员工个人所得税 
    注意：公司可缴纳、也可不缴纳
    = 如果公司待缴纳，计算税后金额会有冲突，需考虑清楚！
```

## 10 公司体现的方式

```java
// 1 工资方式
	基础工资
  社保 = 基础工资 * 6.5%
	银行到账 = 基础工资 - 社保 = 基础工资 * 93.5%
	公司总支出 = 基础工资 * 34.2% + 基础工资
	需要承担的费用 = 公司总支出 - 银行到账 = 基础工资 * 34.2% + 基础工资 -  基础工资 + 社保
							= 基础工资 * 34.2% + 基础工资 * 6.5%
    					= 基础工资 * 40.7%
  费用比 = 需要承担的费用 / 银行到账 = 40.7% / 93.5% = 43.53%
  举例：
  	银行到账 1210.43 需要付出的代价 = 1210.43 * 43.53% = 526.9
    公司总支出 = 1210.43 + 526.9 = 1737.33
    1210.43 还要缴纳个人所得税 19%
 最终结果--- 实际总代价 = 43.53% + 19% = 62.53%
    
// 2 分红方式
	分红金额
	公司税 = 分红金额 * 25%
  费用比 = 分红金额 * 25% / 分红金额 = 25%
  最总结果 --- 实际总代价 = 25% + 19% = 44%
    
    
// 3 总结
    相同的到账金额
    	工资方式 代价 = 到账金额 * 43.53% + 个人所得税部分(两者相同)
    	分红方式 代价 = 到账金额 * 25% + 个人所得税部分(两者相同)
    分红方式少付代价 = 到账金额 * 18.53%
    
    
// 4 工资 + 分红的模式 (推荐)
    -- 通过 “工资+分红”组合 降低综合税负（公司税+分红税＜IRPF累进税）
    -- 步骤1：发工资（降低公司利润），公司税 25%
    -- 步骤2：工资个税 19% (可以增加子女等条件抵扣)
    -- 步骤3：分红 分红税19%(分红税收部分可以抵扣个税，相当于只缴纳了 25%的公司税)，应税金额 = 分红 - 分红预扣税额
    -- 核心
			-- 主要控制 个人所得税 累计方式 控制 19%-46% 控制在最低！！！
			-- 分红预缴税部分，相当于只缴纳了 25% 的公司税，可以抵扣个人所得税部分！
```
